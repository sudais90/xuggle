# xuggle

This repository contains legacy Xuggle-related Java and native build material. It was automatically exported from the Google Code project `xuggle`.

## Repository layout

- `java/` includes Java project material such as `xuggle-utils`.
- `build/` includes supporting build and CxxTest material.
- `repo/` contains stored dependency artifacts and associated metadata.

## Working with the project

Inspect the relevant module's Maven manifests, Makefiles, and source before selecting a build entry point. Different parts of this repository may require a compatible JDK, Maven, Make, or a C/C++ toolchain. No single root build command or tested toolchain version is established here. Preserve the existing dependency metadata and third-party notices when working with bundled code.
